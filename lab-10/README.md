# Lab 10 - Support Vector Machines (SVM)

In this lab, I used the Support Vector Machines (SVM) algorithm to build a classification model on the Iris dataset. The goal was to classify flower species based on their features such as sepal length, sepal width, petal length, and petal width.

I started by loading the dataset using Seaborn and explored it using methods like head() and info() to understand its structure. Then, I performed exploratory data analysis by visualizing relationships between features using pairplots and other plots to observe how the different species are distributed.

Next, I prepared the data by separating the features and target variable, and splitting the dataset into training and testing sets. I then trained an SVM classifier on the training data.

After training the model, I evaluated its performance using classification metrics such as confusion matrix and classification report to measure accuracy and prediction quality.

Finally, I analyzed the results to understand how well the SVM model performs in classifying the Iris species and how it separates the data using decision boundaries. This lab demonstrated the effectiveness of SVM in handling classification problems, especially with clear separable classes.
