# Lab 9 - Random Forest Classification

In this lab, I used the Random Forest algorithm to build a classification model on loan data from Lending Club. The goal was to predict whether a borrower would fully repay a loan or not based on various financial features.

I started by exploring the dataset using methods like info(), describe(), and head() to understand its structure. Then, I performed exploratory data analysis by visualizing relationships between variables such as FICO score distributions, loan purpose, and interest rates using histograms, count plots, and scatter plots.

Next, I prepared the data by selecting relevant features and splitting it into training and testing sets. I trained a Random Forest classifier and evaluated its performance using classification metrics.

Finally, I analyzed the results to understand how well the model predicts loan repayment and how different features influence the predictions. This lab demonstrated the effectiveness of ensemble methods like Random Forest in improving classification accuracy compared to single models.
