In this lab, I used the Talabat orders dataset to analyze the data and build a model to predict the order status. I first explored the dataset to understand its structure and check for missing values.

Then I created some additional features such as order time features and price categories to help the model learn better patterns. After that, I split the data into training and testing sets and trained a Random Forest model using a preprocessing pipeline.

Finally, I evaluated the model using accuracy, a classification report, and a confusion matrix, and visualized the most important features used by the model.
