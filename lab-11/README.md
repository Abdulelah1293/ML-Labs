# Lab 11 - K-Means Clustering

In this lab, I used the K-Means Clustering algorithm to group similar data points into clusters. I started by exploring and preparing the dataset using Pandas functions such as `head()` and `info()`.

Next, I used the Elbow Method and Silhouette Score to determine the best value of K. After selecting the optimal number of clusters, I trained the K-Means model and assigned cluster labels to the dataset.

Finally, I visualized and analyzed the clusters to understand the patterns in the data. This lab demonstrated how K-Means can be used to discover meaningful groups in unlabeled data.
