# Lab 7 - Advertising Click Prediction

In this lab, I used the fake advertising dataset to analyze user behavior and build a logistic regression model to predict whether a user will click on an ad. I first explored the dataset by checking its structure, summary statistics, and visualizing key relationships such as age distribution, area income vs age, and daily time spent on site vs daily internet usage. Then I split the data into training and testing sets, trained a Logistic Regression model on selected numeric features, and evaluated its performance using a classification report. The visualizations helped me understand which features are most important for predicting ad clicks.
