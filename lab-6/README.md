# Lab 6

In this lab, I used a customer dataset to analyze the data and build a linear regression model to predict yearly amount spent. I first explored the dataset to understand its structure, check the summary statistics, and visualize the relationships between the variables. Then I removed the non-numeric columns, split the data into training and testing sets, and trained a Linear Regression model. Finally, I evaluated the model using MAE, MSE, and RMSE, and compared the actual values with the predicted values using a scatter plot.
