# Lab 3 - Analysis
On this lab we did an exploratory data analysis (EDA) on a BMW sales dataset using Python. The goal is to analyze sales performance, identify patterns and visualize them.

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
1. Revenue by Country

- Grouped data by Country
- Calculated total revenue (Amount)
- Sorted results in descending order

2. Revenue by Product

- Grouped data by Product
- Calculated total revenue
- Visualized results using a bar chart

3. Revenue by Sales Person

- Grouped data by Sales Person
- Calculated total revenue
- Displayed top-performing salespeople

4. Correlation Analysis

- Generated a correlation matrix between:
  - Boxes Shipped
  - Amount
- Visualized the correlation using a heatmap

5. Monthly Revenue Trend

- Created a Month column from the Date column
- Grouped revenue by Month
- Plotted a line chart to show revenue trends over time
